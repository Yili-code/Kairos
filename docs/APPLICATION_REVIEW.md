查證日期：2026-10-24。本輪盤點正式資料中的 90 筆競賽紀錄，針對三個潛在候選重新抓取及評估，另閱讀三個候選的官方入口／條款作優先順序比較。90 筆是庫存，不是符合條件的機會數；本輪沒有確認能完全滿足所有限制的機會。

## 最值得先查：書藝智生

官方依據：[淡江大學主辦公告](https://tkutimes.tku.edu.tw/dtl.aspx?no=60832)、[校方轉知及簡章附件](https://cart.ntua.edu.tw/web/news/news_in.jsp?dm_no=DM1560757140522&np_no=NP1791778067267)。已重新取得整份可抽字的 PDF，包含作品範例與提示詞附錄。

- **資格符合**：不限年齡、國籍、居住地，個人限一件。這項結論不依賴可能已過時的年級。作品不得用於其他競賽及非競賽活動，尚須在實際交件時核對作品履歷。
- **價值**：現金首獎 NT$10,000，另有其他名次獎金與獎狀，獲獎作品會展示。符合獎金與公開紀錄目標；沒有參賽人數或勝率證據。
- **期限**：2026/11/16；官方未寫時刻與時區。系統顯示的臺灣時間、當日 24:00 是既有使用者預設，不能當成主辦確認。
- **交付與人工限制**：AI 書法圖像、附音效動畫、題名及說明；圖像 JPG/PNG、影片 MP4/MPG 等，合計不超過 15MB。說明須本人寫 50–100 字，英文可增 50%，禁止 AI 生成。作品生成亦不得擷取實作再生成或人工後製；文字排在圖像下方的整合要求須一併遵守。
- **成本與義務**：報名費未明；線上交件不代表遠端領獎。領獎另通知，能否免實體出席仍未知。模型估算四小時、工具 NT$0，並非實作量測，影片額度、重試及後續仍不確定，不能當六小時保證。
- **權利**：得獎圖文使用權須讓與主辦，不能只摘要成保留著作權。是否願意接受，留給本人決定。
- **下一步**：先以本人 Google 帳戶檢視官方表單的完整聲明，確認遠端領獎條件及作品整合方式，再決定是否製作。本輪只讀公開頁：兩個官方短網址均指向同一表單，但回傳需登入，沒有登入、接受聲明或交件。

影片工具仍須實測：[Flow 產品頁](https://labs.google/fx/tools/flow)與[額度說明](https://support.google.com/flow/answer/16526234)列出免費額度，但[入門說明](https://support.google.com/flow/answer/16353333?hl=en)對訂閱資格的敘述不同，且有尖峰限流。不能因此保證指定帳戶可免費、即時完成動畫。

## 流程驗證與前後差異

三個真實候選各實際跑一次公開抓取、既有模型及隔離的 ingest／推薦卡流程；連結修正後另重跑一次 AKOOL。沒有用正式候選 repository、Telegram 或寄件信箱進行流程測試。

| 相同案例 | 修正前 | 修正後 |
|---|---|---|
| AKOOL 官網入口 | 只取得一頁，漏申請頁及完整規則 | 取得四頁，保留原網域、文件數、時間與安全限制；只移除追蹤參數，保留語系 |
| AKOOL 權利與收益 | 權利摘要只說保留所有權；首獎標成已知現金數字 | 卡片另呈現行銷授權、Premium 限制、logo 規定及獎項組成；未確認的現金拆分降為未知 |
| 書藝智生說明 | 人工限制在內部 components，卡片只有一般交件摘要 | 卡片明列本人撰寫條款及來源 |
| 免費參賽敘述 | `No purchase is necessary` 無法通過費用證據檢查 | 接受此文字變體，但不代表製作工具免費 |

最後以同一批已保存來源及模型輸出重播三案，不再呼叫外部模型；均保持 pending，卡片保留上述限制。這是個案與受控 regression 驗證，不是全體準確率，也沒有實際製作、申請或得獎驗證。
